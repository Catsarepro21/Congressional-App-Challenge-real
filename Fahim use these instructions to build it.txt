
Open the Terminal app on your Mac and run these commands:

1. Install Xcode Command Line Tools:
   xcode-select --install
   (A window will pop up. Click "Install" and agree to the license).

2. Install Homebrew (Mac Package Manager):
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   (Follow the prompt instructions. Run the 2-3 commands printed at the 
   end of the installation to add Homebrew to your system PATH).

3. Install Node.js & CocoaPods:
   brew install node cocoapods

1. Open Terminal and navigate to this project's root folder:
   cd /path/to/Congressional-App-Challenge-real

2. Install npm dependencies:
   npm install

3. Generate the native iOS project files:
   npx expo prebuild --platform ios
   (This creates the "ios/" folder and automatically runs "pod install"
   to link all native module packages).

Choose either the Terminal method (fastest) or Xcode UI method.

--- METHOD A: USING THE TERMINAL (Recommended) ---

1. Navigate to the generated ios directory:
   cd ios

2. Build the release app bundle without code-signing:
   xcodebuild -workspace "SafeScaleHealth.xcworkspace" \
              -scheme "SafeScaleHealth" \
              -configuration Release \
              -sdk iphoneos \
              -derivedDataPath build \
              CODE_SIGNING_ALLOWED=NO \
              CODE_SIGNING_REQUIRED=NO \
              clean build

3. Package the compiled app bundle into an unsigned .ipa:
   mkdir Payload
   cp -r build/Build/Products/Release-iphoneos/SafeScaleHealth.app Payload/
   zip -r app-unsigned.ipa Payload
   rm -rf Payload

   * Your completed installer is "app-unsigned.ipa" inside "ios/" *
